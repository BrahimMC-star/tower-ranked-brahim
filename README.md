# 🏆 Colria Tower Ranked

A competitive tower ranking system built for **Colria**, featuring seasonal leaderboards, player progression, and real-time statistics.

## Features

- 📊 Real-time player rankings
- 🏅 Seasonal leaderboard system
- 📈 Player progression tracking
- ⚡ High-performance architecture
- 🔌 Easy integration with Colria services

## Tech Stack

- Java 21
- Maven
- SQLite / MySQL (depending on deployment)

> 🚧 This project is currently under active development.
